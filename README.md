
# Student Study Planner

## About
Student Study Planner is a beginner-friendly Python project
that helps students organize their study activities.

## Features
- Display a study planner menu
- Add a study task
- View the subjects menu
- Exit the application

## Requirements
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python main.py
